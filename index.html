    Add Quietest.

    Install from the Chrome Web Store. No sign-up, no setup ceremony.

  2. 02

    Open a pull request.

    Head to Files changed on GitHub. Test files are muted automatically.

  3. 03

    Review at your pace.

    Use the Quietest button to switch views. Your tests are always a click away.

Prefer to install from a ZIP? +
  1. Download the latest ZIP and unzip it into a folder you’ll keep.
  2. Open chrome://extensions/ in a new tab and turn on Developer mode.
  3. Click Load unpacked and select the unzipped folder.

ZIP installs do not update automatically. Download the latest release again to update.
